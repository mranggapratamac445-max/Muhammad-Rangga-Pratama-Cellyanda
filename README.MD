Kesimpulan Hasil UTS Machine Learning

Berdasarkan hasil pengolahan data, metode Linear Regression menunjukkan hubungan positif antara biaya iklan dan penjualan, dengan koefisien sebesar 9,0379 dan nilai \\(R^2\\) sebesar 0,9868, sehingga model mampu menjelaskan sekitar 98,68% variasi penjualan pada data pengujian. Pada Gradient Descent, learning rate 0,02 memberikan hasil yang mendekati Normal Equation, sedangkan 0,1 tidak stabil.

Sementara itu, Logistic Regression berhasil mengklasifikasikan email spam dan bukan spam dengan akurasi, precision, recall, dan F1-score sebesar 100% pada data pengujian. Pengujian threshold menunjukkan bahwa threshold 0,5 dan 0,7 sama-sama menghasilkan F1-score tertinggi. Secara keseluruhan, kedua metode dapat digunakan sesuai kebutuhan, yaitu Linear Regression untuk memprediksi nilai penjualan dan Logistic Regression untuk mengklasifikasikan email. Namun, hasil yang sangat baik pada data pengujian belum menjamin performa yang sama pada data baru.
